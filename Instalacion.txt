backend: 
1. Crear y activar el entorno virtual:
python -m venv venv

# En Windows:
venv\Scripts\activate
# En Mac/Linux:
source venv/bin/activate

2. Instalar las dependencias:
pip install -r requirements.txt

3. Crear .env:
DATABASE_URL="postgresql://postgres:postgres@localhost:5432/foodstore_db"

SECRET_KEY="una_contrasena_super_larga_y_dificil_de_adivinar_que_nadie_sepa_12345!"
 - - - 
 pip install fastapi uvicorn sqlmodel psycopg2-binary alembic "passlib[bcrypt]" "python-jose[cryptography]" "python-multipart"
- - - 
4. Crear las tablas en la Base de Datos:
alembic upgrade head

5. Encender el servidor:
uvicorn main:app --reload 
# (O uvicorn app.main:app --reload, dependiendo de dónde esté tu main.py)
